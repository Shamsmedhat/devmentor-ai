# Session catalog checklist

Not for ingestion - files starting with `_` in this folder are never ingested.

These are the 106 recorded sessions that were in the knowledge base as transcripts (recorded for the June 2026 cycle). For each session of the current cycle:

1. Copy `_TEMPLATE.md` to `<cycle>-<slug>.md` (e.g. `cycle-5-rhf-zod-intro.md`) and fill it in.
2. Use the old transcript in `kb-backup/video-transcripts/<title>.txt` as raw material for the summary.
3. Ingest it: `yarn kb:ingest-doc kb-docs/sessions/<file>.md session-<cycle>-<slug> --source-type session`
