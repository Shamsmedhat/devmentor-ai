# Rose App — Textarea Component

Textarea — حقل نص multi-line بـ label فوقه، حواف rounded.

## Behavior / States
- **Auto-resize** — بيكبر مع المحتوى (اختياري).
- **Character counter** — عداد أحرف لما يتحدّد maxLength.
- **Error state** — label + border أحمر.
- **Disabled** — باهت ومعطّل.

بيدعم dark/light + RTL/LTR.

## Tokens
error = danger red-600 #DC2626 · focus ring = primary Maroon.
