# Rose App — Combobox (Dropdown) Component

Combobox — قائمة منسدلة فيها بحث (Dropdown مع search).

## Behavior
- **حقل بحث** جوّه القائمة بيفلتر العناصر.
- **Keyboard navigation** (أسهم + Enter للاختيار).
- **Click-outside** بيقفل القائمة.
- **Error / Disabled** states.

بيدعم dark/light + RTL/LTR.
