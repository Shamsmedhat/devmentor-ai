# Rose App — Select Component

Select — قائمة اختيار منسدلة (single select) بـ chevron (▾) + "Select an option" كـ placeholder.

## Variants / States
- **Single select** — اختيار عنصر واحد من قائمة.
- **Placeholder** — نص افتراضي قبل الاختيار.
- **Error state** — border أحمر.
- **Disabled** — معطّل.

بيدعم dark/light + RTL/LTR.
