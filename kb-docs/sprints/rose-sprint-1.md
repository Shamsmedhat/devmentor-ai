# Rose App — Sprint 1 plan (السبرنت الأول)

> **ملخّص بالعربي:** السبرنت الأول (Sprint 1) في مشروع Rose App في ايليفيت (Elevate Tech) فيه 6 تاسكات: تجهيز المشروع، و4 تاسكات Design System (الـ Input، الـ Button والـ Checkbox والـ Badge والـ Mode Toggle، الـ Pagination والـ Toast والـ Tabs والـ Textarea، الـ Dropdown والـ Select والـ Menu)، وأول جزء من الـ Home Page (الـ Header والـ Footer والـ Notifications). توزيع التاسكات على السبرنتات ممكن يختلف من جروب للتاني.

Sprint 1 of the Rose App website (Elevate Tech bootcamp). This is the current plan: a cohort may move a task to a later sprint or add a new one. The task content itself lives in each task document.

## Tasks in Sprint 1 (6 tasks)

1. **Project Setup: Rose App Team Repository & Design System** (epic: Project setup) - ريبو الفريق، Next.js 16 + TypeScript، Tailwind CSS وshadcn/ui وnext-intl، الألوان والـ semantic tokens، خطوط Sarabun وTajawal، عربي/إنجليزي (RTL/LTR)، والـ Light/Dark/System modes.
2. **Design System: Input Component & Variants** (epic: Project setup) - الـ Input بـ 7 أنواع: Text، Search، Number، File، Phone، OTP، Password.
3. **Design System: Buttons, Checkbox, Badge & Mode Toggle** (epic: Project setup) - Button بـ 6 variants + Loading، Checkbox، Badge بـ 6 variants، وMode Toggle (Light/System/Dark).
4. **Design System: Pagination, Toast, Tabs & Textarea** (epic: Project setup) - Pagination مربوطة بالـ URL، Toast بـ 3 variants، Tabs، وTextarea.
5. **Design System: Dropdown (Combobox), Select & Menu** (epic: Project setup) - Combobox فيه بحث (Popover + Command)، Select، وMenu.
6. **Home Page: Header (Unauthenticated), Footer & Push Notifications** (epic: Home Page) - الـ Header من غير تسجيل دخول، الـ Footer مع الـ Newsletter (API)، لوحة الـ Notifications، والـ Push Notifications.

## Epics

- **Project setup:** repository, libraries, design tokens, fonts, i18n, theme modes, and the reusable design-system components.
- **Home Page:** Sprint 1 covers the unauthenticated Header, the Footer (including the newsletter subscription), the notifications panel, and push notifications. Later sprints cover the Hero section, the About section, the other Home page sections, and responsive layouts.
